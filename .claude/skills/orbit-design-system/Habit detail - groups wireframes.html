Habit detail sheet · the "groups this habit belongs to" block

Four ways to show the rotations a habit lives in

Tapping a habit in any list opens this read-only detail sheet — name, images, note — with an Edit ✎ that flips the same sheet into the editor. A habit can rotate in more than one group, so the sheet needs to name them. Each card below shows the full sheet; the coral-dashed block is the only part that differs.

Skeleton = existing sheet content (name, images, note), dimmed for context
Coral-dashed = the groups treatment under exploration
A · Quiet chip cluster
Group names as small pills, each with a mini orbit badge. Wraps to a second line, ends with a dashed + Add. Lowest vertical cost — best when a habit usually sits in one or two groups. Tap a chip to jump to that rotation. Doesn't show where the habit sits in each queue.

C · Literary one-liner
The lightest touch: a single sentence in the house voice — "Rotates in Core and Mobility." Names are tappable. A small Manage rotations link handles membership. Most in-keeping with the calm tone, but carries no cadence or standing.

Notes & open questions
  • I drew Hollow hold as living in two groups (Core + Mobility) to show the multi-group case. In today's data each habit sits in one group — confirming habits can belong to many is the real model change here.
  • A and C are quiet and cheap on space; B and D add the "where does it sit in each ring" standing, which feels true to the orbit metaphor. They cost more height.
  • Whichever we pick, I'll also finish the detail sheet itself — right now there's only the description-feature reader; this becomes the canonical tap-to-open habit sheet with Edit flipping it in place (no stacked sheets).
