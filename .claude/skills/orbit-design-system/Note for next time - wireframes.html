A whisper for next time

An ephemeral, one-line note that past-you leaves for future-you at the moment of ticking. Lives once — read on next pickup, then consumed. Different from the habit description (persistent metadata). Three things to design: 1) how it gets in, 2) how it shows up next time, 3) the indicator that one is waiting.

Concept · the whisper

One ephemeral line. Written on tick, read on next pickup, gone after.

It's not a habit description (those are persistent and live in the form sheet you already designed). It's a self-addressed sticky note that travels with the rotation cursor — attached to the next instance of this habit, not to the habit itself.

Picks below. The recommended path is highlighted in coral.

  • Insertion: 1B — a slim "+ for next time" affordance under Mark done that expands inline into a single italic field. Lowest friction, never blocks the tick.
  • Display: 2A — a coral-tinted "From last time" card directly above the habit name on the hero. Impossible to miss; doesn't compete with the ring.
  • Indicator: 3A — a small coral italic quote glyph " next to queued habits that have a whisper waiting. Read-only marker; tapping the row still ticks (the whisper appears on hero, not on a list row).

Constraints
  • One line. ~140 chars hard cap.
  • Plain text (no markdown — the habit description does that job).
  • Stored on the habit. Cleared the moment the user opens the hero of that habit again.
  • Undo within the existing 5.5s undo window restores it.

Open questions
  • Clearing trigger. On view, on tick, or on next ping?  → recommend: on tick.
  • Skip turn. Does skipping clear the whisper or carry it forward?  → carry. The next instance is still next.
  • Out-of-order tick. If the user ticks a different habit in the queue, the original whisper stays on its original habit. (Whispers travel with the habit, not the cursor.)
  • Carried habits. If a habit carries over (missed day), the whisper waits with it.
  • Notification copy. When pinged, push body becomes: "A whisper from last time." instead of the cadence label.
  • One whisper at a time. Writing a new one while one already pending overwrites with a soft confirm.
Not in scope (yet)
  • Whisper history / archive.
  • Multiple whispers per habit.
  • Voice notes, photos, attachments.
  • Whisper inside the system notification (just the line in push body — no actions).
